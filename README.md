# Алгоритмы по шагам

Интерактивный сайт-тренажёр по алгоритмам и структурам данных: сортировки, поиск, индексация, хеширование, кодирование и деревья. Каждая тема — с пошаговой визуализацией, объяснениями, псевдокодом и мини-тестом для самопроверки. Все вычисления выполняются локально в браузере.

## Запуск

Откройте `index.html` в браузере — сервер и сборка не нужны. При желании сайт разворачивается на GitHub Pages.

## Особенности

- Пошаговый плеер: кнопки «Назад / Дальше», ползунок шага, режим «Авто», клавиши ← и →.
- Для каждой темы — секция **«Псевдокод»** и карточка **«Проверь себя»** с самопроверкой.
- Выезжающая панель с реализацией на C, синхронизированной с текущим шагом.
- Светлая и тёмная темы, переключение кнопкой в шапке.
- Оформление в стиле Claude: серифные заголовки, тёплая палитра, терракотовый акцент.

## Разделы

| Файл | Что показывает |
|---|---|
| `index.html` | Мастер-страница: шесть разделов сайта |
| `sort.html` | Девять сортировок, счётчики сравнений C и перемещений M |
| `binary-search.html` | Бинарный поиск символа: тип 1 (точное вхождение) и тип 2 (позиция вставки) |
| `indexing.html` | Индексный массив символов, направление и фильтры «гласные / согласные» |
| `hashing.html` | Хеш-таблица настраиваемого размера: цепочки и открытая адресация |
| `coding.html` | Кодирование: коды Шеннона, Фано, Хаффмана и Гилберта—Мура |
| `trees.html` | Мастер-страница раздела «Деревья» |

## Страницы деревьев

| Файл | Что показывает |
|---|---|
| `isdp.html` | ИСДП — идеально сбалансированное дерево поиска |
| `sdp.html` | СДП — случайное дерево поиска |
| `sdp-delete.html` | Удаление из СДП (три случая) |
| `avl.html` | Построение АВЛ-дерева, повороты LL/RR/LR/RL |
| `avl-delete.html` | Удаление из АВЛ-дерева с балансировкой |
| `btree-m.html` | Б-дерево порядка m (страницы от m до 2m элементов) |
| `btree.html` | Двоичное Б-дерево поиска (ДБД): страницы из 1–2 ключей, горизонтальные связи |
| `optimal-exact.html` | Оптимальное дерево поиска, точный алгоритм динамического программирования |
| `optimal-approx.html` | Оптимальное дерево поиска, два приближённых алгоритма |

## Общие файлы

- `assets/style.css` — оформление, светлая и тёмная темы, адаптивность.
- `assets/core.js` — парсинг ввода, раскладка и рисование деревьев, пошаговый плеер, темы и мини-тесты.
- `assets/algo.js` — столбики сортировок, карманы цифровой сортировки и вспомогательные визуализации.
- `assets/pocket.js` — выезжающая панель с кодом на C.

## Методички

В `metodics/` лежат задания по курсу (обработка массивов, списков, деревьев, кодирование данных) — по ним добавляются новые темы.
