Сортировка структур по сложному ключу

Сортируем телефонный справочник — массив записей с несколькими полями. Ключ сортировки можно менять: по умолчанию это составной ключ «фамилия + имя», но можно выбрать любое поле и направление. Используется сортировка вставками (не пузырьковая).

Сортировка устойчивая: при равном ключе записи сохраняют исходный порядок. Сложный ключ сравнивает сначала фамилию, затем имя.
Что такое сложный (составной) ключ

Сложный ключ состоит из нескольких полей, которые сравниваются по очереди: сначала старшее поле, при равенстве — следующее. Для справочника «фамилия + имя» сначала сравниваются фамилии; если они совпали, сравниваются имена. Это даёт привычный алфавитный порядок: все Ивановы идут подряд, а внутри — по имени.

Псевдокод 
Алгоритм: сортировка записей вставками по ключу
  Вход: массив записей a, ключ key, направление dir

  сравнить(x, y):
      для каждого поля f ключа (фамилия, имя, …):
          если x[f] < y[f]: вернуть −1
          если x[f] > y[f]: вернуть +1
      вернуть 0

  для i от 1 до n−1:
      key ← a[i]; j ← i−1
      пока j ≥ 0 и сравнить(a[j], key)·dir > 0:
          a[j+1] ← a[j]; j ← j−1
      a[j+1] ← key
